## 🎮 Gameplay

You control a character from a first-person perspective and must complete a scenario consisting of **10 stages** featuring **2-3 distinct mechanics**. The game includes:

- 🧭 **First-person controls** with intuitive movement
- 🎬 **Animated sequences** to enhance immersion
- 🖥️ **User interface** for interaction and feedback
- ✅ **Error checking** — incorrect actions (wrong sequence, entering dangerous zones) are detected and handled
- 🏁 **Final result screen** showing your performance

---

## 🎯 Purpose

This project was created as a **test assignment** for a potential employer to demonstrate proficiency with Unreal Engine Blueprints. The assignment required implementing a complete scenario with multiple mechanics, UI, and error handling.
